# FORTUNE LAB

悩みを吐き出せる場所を入口に、独自の「12の星座」で自己理解を深め、5分の「今日の実験」で行動につなげるサイトのプロトタイプです。占いアフィリエイトで収益を立ち上げ、自社の診断・商品へ広げることを想定しています。

> 悩みは、あって当然。悩むのは、ちゃんと生きている証拠。

- 否定しない：悩みを「直すべきもの」として扱わない
- 急がせない：解決策より先に、吐き出して言葉にする場を用意する
- 小さく動く：最後は必ず5分以内の「今日の実験」で終わる

---

## 機能の特徴

### 1. 書いた文章が外に出ない「吐き出しノート」

- 文章は**ブラウザの中だけ**で照合に使い、送信も保存もしない。サーバーが不要で、運営者も読めない
- 書いた内容と選んだキーワードから、**今夜の星座と関連記事を自動で提案**する
- 「夜空に流す」で文章を消す儀式があり、書くこと自体が区切りになる
- つらさを示す言葉を端末内で検知すると、星座の返事より先に**相談窓口を表示**する

### 2. 文章を残さずに振り返れる「種の記録」

- 残すのは星座・キーワード・表示した記事だけ。悩みの中身ではなく**悩みの傾向**が残る
- 過去の種を見返し、読んだ記事や「やってみた」実験をあとから確認できる
- 記録は端末内だけ。いつでも1件ずつ／すべて消せる。記録しない選択もできる

### 3. 独自の「12の星座」

- 一般的な星座占いではなく、「人が生きていくうえで大切な12の観点」を自然のモチーフにした**オリジナルの体系**（指名検索・シリーズ認知の軸になる）
- 生まれ月で決まる「生まれ星座」と、悩みで変わる「今夜の星座」の2つの使い方
- すべての星座を「星座の声（占い）→ 思考のクセ（自己分析）→ 今日の実験（自己啓発）」の同じ3段で語るので、占い・自己分析・行動が1つの流れになる

### 4. 「吐き出す → 知る → 変わる」がつながる導線

- **吐き出す**：悩みを書き、受け止められる
- **知る**：12問診断・思考のクセ・自分の星図で、悩みやすい観点に気づく
- **変わる**：5分以内の実験ライブラリと実験の記録で、小さく動く
- 書いても整理しきれない人にだけ「話して整理する（電話占い）」を案内する。同じ星座で何度も吐き出している、実験を続けても変わらない、といった**本当に必要な場面で出す**ので、売り込みにならない

### 5. 「できたこと」だけを数える

- 実験の記録は、やってみた数だけを表示し、できなかった日は数えない
- 診断で揺れがなければ「大きく揺れている星座はなさそう」と返し、悩みを作り出さない
- 文言はすべて「否定しない・急がせない」のルールに沿う（使わない言葉を決めている）

### 6. 星座ごとのフォルダで増やせるコンテンツ

- 星座の基本データ・星座ページ・記事を**星座ごとのフォルダ**で管理する
- 記事はファイルを1つ置くだけで、記事一覧・星座ページ・吐き出しの関連記事・トップの新着・知る／変わるに**自動で載る**
- 星座ページは、詳細データを書いた星座だけ詳細版になり、ほかはテンプレ版で自動表示される。12星座を少しずつ育てられる
- 記事の種別（悩み／知る／変わる）は「読み終えたときに何が残るか」という基準で決める

### 7. 信頼と安全を先に設計

- 全ページにPR表記、広告リンクは比較記事だけ、1記事のPR枠は最大2つ、吐き出しの直後に広告を置かない
- 占いは娯楽と自己理解のきっかけと明記し、医療・法律・お金の判断は専門家へ案内する
- 相談窓口一覧・占いとの付き合い方・プライバシーポリシーなどを、フッターから常にたどれるようにしている

## 1. 開発環境

Vite + TypeScript（strict）。フレームワークは使わず、1つの HTML をハッシュURLで切り替える構成です。

```bash
npm install
npm run dev        # 開発サーバー（http://localhost:5173/）
npm run build      # 型チェック → dist/ にビルド
npm run typecheck  # 型チェックのみ
```

## 4. 12の星座

既存の12星座ではなく、「人が生きていくうえで大切な12の観点」を自然のモチーフに置き換え、季節の巡りで12か月に割り当てた独自の星座です。

| 月 | 星座 | 観点 | 月 | 星座 | 観点 |
|---|---|---|---|---|---|
| 1 | 星 hoshi | 未来・希望 | 7 | 海 umi | 自己実現 |
| 2 | 根 ne | 家族・ルーツ | 8 | 太陽 taiyo | 仕事・役割 |
| 3 | 風 kaze | 変化・転機 | 9 | 月 tsuki | 自己理解 |
| 4 | 花 hana | 恋愛・愛情 | 10 | 実 mi | お金・豊かさ |
| 5 | 森 mori | 人間関係 | 11 | 山 yama | 環境・居場所 |
| 6 | 雨 ame | 休息・心と体 | 12 | 川 kawa | 時間・習慣 |

- **生まれ星座（固定）**：生まれ月で決まる、その人が大切にしやすい観点
- **今夜の星座（変わる）**：いま悩んでいる観点。吐き出しノート・カード・12問診断で決まる

各星座は「星座の声（占い）→ 思考のクセ（自己分析）→ 今日の実験（自己啓発）」の3段で語ります。

## 5. 主な機能

### 吐き出しノート（トップ）

1. 文章を書き、近いキーワードを選ぶ（複数可・選ばなくてもよい）
2. 「吐き出す」で、文章とキーワードを**ブラウザ内で**照合し、今夜の星座と関連記事を最大3本表示
3. 文章は照合に使うだけで、**送信も保存もしない**
4. 「種として記録する」（初期値オン）なら、星座・キーワード・表示した記事だけを端末内に保存
5. 「夜空に流す」で文章を消す
6. つらさを示す言葉（「消えたい」など）があれば、相談窓口の案内を最優先で表示

照合のスコア：選んだキーワード +3、星座の照合語1つ +1。記事は星座一致 +3（次点の星座 +1）、記事の照合語1つ +2。

### 種の記録（`#seeds`）

- 過去の種を新しい順に表示（日時・星座・キーワード・表示した記事と既読・今日の実験の「やってみた」）
- 星座ごとの件数で絞り込み、1件ずつ／すべて削除
- 同じ星座が14日以内に3回以上なら「話して整理する」を控えめに案内

保存する内容（文章は保存しない）：

```ts
interface Seed {
  id: string; at: string; star: StarId;
  tags: string[];      // 選んだキーワード
  matched: string[];   // 文章から見つかった辞書の語
  shown: string[];     // 表示した記事
  read: string[];      // 開いた記事
  experimentDone: boolean;
}
```

### 星座ページ（`#pillar/<星座>`）

- `pillar.ts` がある星座は**詳細版**（今は森のみ）：吐き出し → 星座とは → 強みとつまずき → あって当然の悩み（記事へリンク）→ 自己分析ワーク → 1週間の実験 → 話して整理する → 記事と関連する星座 → FAQ
- 無い星座は `star.ts` から**テンプレ版**を自動生成（今日の実験の後に1週間の実験も出る）
- 1週間の実験は詳細版・テンプレ版とも `star.ts` の `week`（月曜始まり7日分。曜日は自動で付く）
- 自己分析ワークは部品で定義：`scale`（段階を選ぶ）／`checklist`（当てはまる数）／`cards`（境界線の例）

### 知る（`#self`）

1. 今夜の星座診断（12問。各星座の `star.ts` の `question`。3段階で回答し、最高点の星座が結果。回答は保存しない）
2. 12の思考のクセ一覧
3. あなたの星図（種の数を星座別に棒グラフ表示）
4. 知る記事（`kind: 'self'`）

### 変わる（`#growth`）

1. 実験の記録（種の「やってみた」から、今月と合計。できなかった数は出さない）
2. 今日の実験ライブラリ（星座の実験＋詳細版の悩み別の実験。星座で絞り込み）
3. 1週間の実験（各星座の `star.ts` の `week`。トップで選んだ生まれ月の星座を最初に表示し、12星座から切り替えられる。生まれ月が未選択なら、いちばん多い種の星座 → 森の順）
4. 変わる記事（`kind: 'growth'`）
5. 続けても変わらないときの「話して整理する」案内

### 運営・ポリシー系ページ

運営者情報・広告掲載ポリシー・占いとの付き合い方・相談窓口一覧・プライバシーポリシー。全ページ共通のフッターからのみリンクし、トップには中身を出しません。

## 6. コンテンツの増やし方

### 記事を追加する

その星座の `articles/` にファイルを1つ置くだけです。星座はフォルダ名、URLはファイル名から決まります。

```ts
// src/stars/ame/articles/sleep.ts → #article/ame/sleep
import { defineArticle } from '../../../lib/define';

export default defineArticle({
  kind: 'growth',               // 省略時は 'worry'
  no: 34,                       // LAB NOTE 通し番号（サイト全体で一意）
  title: '眠れない夜に…',        // 【雨の星座】は自動で付く
  tags: ['休息'],
  keywords: ['眠れ', '夜'],      // 吐き出しの文章と照合する語
  targetKeywords: ['眠れない 不安'],
  updated: '2026-11-30',
  body: { /* lead, ventPrompt, experiment など */ }, // 無ければ「準備中」
});
```

記事一覧・星座ページ・吐き出しの関連記事・トップの新着・（kind に応じて）知る／変わるに自動で載ります。見本は `src/stars/mori/articles/tired.ts`。

### 星座ページを詳細版にする

`src/stars/<星座>/pillar.ts` を置きます。見本は `src/stars/mori/pillar.ts`。

### 運営・ポリシー系ページを追加する

`src/pages/<id>.ts` を置くと `#<id>` で表示され、フッターに並びます（順番は `src/data/pages.ts` の `FOOTER_ORDER`）。

### 自動チェック

フォルダ名と id の不一致、記事の通し番号の重複、12星座・12か月がそろっていない場合は、ブラウザのコンソールにエラーが出ます。

## 7. 記事の種別（kind）の判定基準

「読み終えたときに何が残るか」で決めます。

| kind | メニュー | 読後の一文 | 本文の中心 | KWの形 |
|---|---|---|---|---|
| `worry` | 悩み×星座 | 「悩んでいいんだ」 | 悩みを受け止める | 〇〇 疲れた／つらい |
| `self` | 知る | 「だから私はこうなるのか」 | 思考のクセ・強み・価値観 | 〇〇 性格／なぜ〇〇してしまう |
| `growth` | 変わる | 「これをやってみよう」 | 具体的な行動と手順 | 〇〇 方法／やり方／コツ |

**知る記事の条件**：クセ・強み・価値観が中心（手順ではない）／クセは「つまずき」と「強み」の表裏で書く／セルフチェック等のワークを1つ入れる／最後は星座ページと診断へつなぐ。

**迷いやすい点**：全記事の最後に「今日の実験」があるので、実験があるだけでは `growth` にしない。タイトルに「方法」「やり方」なら `growth`、「なぜ」「性格」「クセ」なら `self` が目安。

## 8. 言葉とCTAのルール

**使う言葉**：「そう感じるのは自然なこと」「悩むのは、大切にしているから」「答えを出さなくても大丈夫」「できたら、それで成功」

**使わない言葉**：「気にしすぎ」「考えすぎ」／「ポジティブに考えよう」の押し付け／不安をあおる断定／「必ず当たる」「100%的中」

**CTAの原則**

- ASP直リンクは比較記事（/compare/）だけ
- 1記事のPR枠は最大2つ
- 吐き出し欄の直後に広告を置かない
- 料金・特典は「公式で確認」と明記
- 「話して整理する」は、書いても整理しきれない人への選択肢として案内する（売り込まない）

## 9. プライバシーの設計

| データ | 扱い |
|---|---|
| 吐き出しノートの文章 | ブラウザ内で照合に使うだけ。送信も保存もしない |
| 種（星座・キーワード・記事） | 「種として記録する」を選んだときだけ、端末の localStorage に保存。サーバーには送らない |
| 生まれ月 | 選んだときに端末の localStorage に保存（次回の初期値と「変わる」の1週間の実験に使う）。サーバーには送らない |
| 診断の回答 | 結果表示に使うだけ。保存も送信もしない |

将来サーバーで集計する場合は、送るのは星座とキーワードの件数だけにし、表記を「文章は送信・保存されません」に変えてプライバシーポリシーを改定します。

### 既知の小さな課題

- 照合は部分一致のため、「親友」の「親」で根の星座に当たるなど誤判定がある（照合語の調整で改善）
- 森の星座の「少し考えさせて」の実験が、ライブラリで語尾違いの2件として出る
- 文章から見つかった照合語も種に保存している。共有端末への配慮が必要なら、選んだキーワードだけを保存する形に変更できる
